# TaskWing

A lightweight, accessible Chrome extension that lets non-technical users record, edit and replay repetitive browser tasks.

**Target release:** 12 Feb 2027 on the Chrome Web Store.

## Features (planned)

- Record clicks and typing on buttons, links, text fields, checkboxes and dropdowns
- Replay flows (tested on mail.google.com)
- Saved flows persist after a browser restart
- Block-based editor: edit blocks, reorder by drag-and-drop
- Import/export flows as JSON

## Not included

Desktop app, user accounts, cloud sync, analytics, other browsers, scheduling/loops/conditions, guaranteed replay on every website.

Load the extension in developer mode:
 
1. Clone the repo.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (toggle in the top right).
4. Click **Load unpacked** and select the cloned folder.
5. TaskWing appears in your extensions list. Click the puzzle icon in the toolbar and pin it to use it.
